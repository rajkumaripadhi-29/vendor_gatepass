# Tata Steel SEZ Vendor Pass Management System

A web-based Vendor Pass Management System developed to digitize and streamline the vendor entry pass management process for Tata Steel Special Economic Zone (SEZ).

The system replaces the traditional manual process with a centralized digital platform for vendor pass generation, record management, pass validity tracking, company-wise management, and administrative control.

---

##  Project Overview

The Tata Steel SEZ Vendor Pass Management System is designed to simplify and automate the process of creating and managing vendor entry passes.

The system provides secure authentication for authorized users and allows them to create digital vendor passes by entering vendor details, company information, work order details, medical validity, and pass duration.

Generated passes can be previewed and downloaded in image format for printing and verification.

The system also provides facilities to manage active, expired, and expiring passes, search and filter records, manage company-wise pass information, export records, renew passes, and delete outdated records through administrator access.

---

## Objectives

- Digitize the manual vendor entry pass process
- Reduce paperwork and manual effort
- Improve security through authentication
- Generate vendor entry passes digitally
- Track pass validity efficiently
- Maintain vendor pass records centrally
- Monitor active, expired, and expiring passes
- Manage vendor passes company-wise
- Improve accuracy and operational efficiency
- Provide controlled administrative access

## Features

### Login Module

The Login Module provides secure authentication using Firebase Authentication.

Features include:

- User login
- Password visibility toggle
- Error handling
- Forgot password
- Password reset
- Session-based authentication

Only authorized users can access the dashboard and application modules.

---

### Dashboard Module

The Dashboard provides an overview of the vendor pass system through important statistics.

It displays:

- Total generated passes
- Active passes
- Expired passes
- Passes expiring today

This allows users to quickly monitor the overall status of vendor passes.

---

### Generate Pass Module

The Generate Pass Module allows authorized users to create vendor entry passes digitally.

Users can enter information such as:

- Vendor details
- Company name
- Work order information
- Medical validity
- Pass duration
- Issue date
- Expiry date

The system validates the entered information and generates a pass preview.

Generated passes can be downloaded as an image for printing and verification.

---

### Company Module

The Company Module provides company-wise management of vendor pass records.

Features include:

- View company-wise pass records
- Search companies
- Filter records
- Track vendor passes associated with companies
- Export records
- Export company-wise records

---

### Pass Record Module

The Pass Record Module stores and manages all generated vendor pass records.

Users can:

- Search pass records
- Filter records
- View pass details
- Renew passes
- Track generated passes

---

### Pass Details Module

The Pass Details Module helps users monitor the validity of vendor passes.

It provides information about:

- Expired passes
- Expiring passes
- Pass validity
- Search and filtering

This helps users identify passes that require timely action.

---

### Delete Record Module

The Delete Record Module is available for authorized administrators.

Administrators can remove:

- Unwanted pass records
- Outdated pass records

This helps maintain accurate and updated records.
